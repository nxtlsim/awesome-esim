# Contribution Guidelines

Thanks for helping make **Awesome eSIM** better. Please make sure your pull request follows these rules:

- **One item per pull request**, with a clear title such as `Add lpac-ui`.
- **Format:** `- [Name](https://link) - Short description ending with a period.` Keep descriptions neutral and factual: no marketing claims, prices or superlatives.
- **Placement:** add the entry at the end of the most relevant section.
- **Quality:** the link must work, the project must be relevant to eSIM / eUICC / SIM provisioning or eSIM connectivity, and open-source projects should be actively maintained (a commit in the last 12 months) with a README in English.
- **Providers welcome on equal terms:** any eSIM provider may add its public API docs, SDKs or open-source tools. Plan listings, referral links and coupon codes are not accepted.
- **No duplicates.** Search the list first.
- Check your spelling and grammar, and remove trailing whitespace.

Maintainer note: this list is maintained by NXTL eSIM, which also operates an eSIM service. If you think an entry is biased or out of date, open an issue.
